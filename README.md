# routerjockey-labs

Companion labs and code for the series on [routerjockey.com](https://routerjockey.com/).

Each folder belongs to one series and is named after the series' page (`routerjockey.com/series/<folder>/`). Inside it, `part-N/` folders hold the files that part shows, so you can clone instead of copy and paste. A shared `lab/` folder holds a lab that several parts use.

The labs run under [netlab](https://netlab.tools/) with containerlab. Vendor images aren't included. Each post explains how to get the ones it uses.
