# Git for Network Engineers

Companion files for the [Git for Network Engineers](https://routerjockey.com/series/git-for-network-engineers/) series, which builds a small Ansible runbook repo (`runbooks-demo`) and puts it under version control on GitHub.

- `part-1/` holds the starting repo, with the README, `inventory.ini`, the two playbooks and the `.gitignore`, from [Part 1: From Zero to Your First Pull Request](https://routerjockey.com/git-for-network-engineers-part-1/).
- `part-3/` holds the `.gitattributes` file and the git aliases, from [Part 3: Reading the Crime Scene](https://routerjockey.com/git-for-network-engineers-part-3/).
- `part-4/` holds the GitHub Actions lint workflow, the branch protection JSON, the pre-commit config and the CODEOWNERS file, from [Part 4: Going Pro](https://routerjockey.com/git-for-network-engineers-part-4/).

Part 2 is all recovery commands run against the Part 1 repo, so it has no folder of its own. The inventory addresses are documentation examples, not real devices.
