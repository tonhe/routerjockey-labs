# Labs as Code

Companion files for the [Labs as Code](https://routerjockey.com/series/labs-as-code/) series, building network labs from netlab topology files.

- `part-1/` holds the three-router FRR and OSPF `topology.yml` from [Part 1: Install netlab, Build a Lab in Five Minutes](https://routerjockey.com/labs-as-code-part-1/).
- `part-2/` holds the eight router Arista cEOS `topology.yml` (OSPF ring, eBGP multihop egress steering, BFD) from [Part 2: Real Images, Real Topology](https://routerjockey.com/labs-as-code-part-2/).
